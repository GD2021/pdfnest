How to Combine PDF Files on Windows 10 and 11

PBy the PDFNest Team·November 2, 2026·5 min read

Windows opens and prints PDFs perfectly well, but it cannot combine them. There is no merge option in File Explorer, in Edge’s PDF viewer or in the Photos app, and the workarounds people suggest tend to produce a worse document than the ones you started with. The reliable route needs nothing installed: a browser tool that merges the files on your own PC.

What Windows can and cannot do with PDFs

Windows 10 and 11 can display PDFs in Edge, print them, and create a new PDF from anything printable using Microsoft Print to PDF. What they cannot do is open several PDFs and join them into one document. That is not a setting you have missed; the feature simply is not part of Windows.

That gap is why so many “merge PDF” searches come from Windows users, and why the answers vary so much. Some suggest paid desktop software, some suggest uploading files to a website, and some suggest clever-sounding workarounds with Word or the print dialog. Each has a cost — money, privacy or quality.

A browser-based merger avoids all three. It runs in Edge or Chrome, which you already have, it processes the files on your PC rather than a server, and it copies pages exactly rather than re-printing them. The rest of this guide uses that route.

Get the files ready in File Explorer

Put the PDFs you want to combine into one folder. It makes them easy to select together, and it gives you somewhere obvious to save the merged result. If the files came as email attachments, save each one rather than opening them from the mail app’s temporary location.

Rename them in the order you want them to appear — 1-cover.pdf, 2-application.pdf, 3-references.pdf. You can still change the order during the merge, but numbered names make mistakes obvious at a glance, and they keep the folder tidy if you need to rebuild the pack later.

Check that each file opens. A PDF that will not open on its own will not merge correctly either, and it is easier to find the bad file now than to work out which part of a 40-page combined document is broken. If one refuses to open, the guide to PDFs that won’t open covers the usual causes.

Combine the PDFs in Edge or Chrome

Open Merge PDF and drag the files from File Explorer onto the page, or click to choose them. Each file appears in a list. Drag entries up or down until the order is right, remove anything you added by mistake, then merge and download the combined PDF.

The merge happens inside your browser on your own computer. The documents are never uploaded, which matters on a work PC where policy may prohibit sending files to unknown websites, and for any personal document — tax forms, statements, contracts — that you would not want copied to someone else’s server.

Pages are copied, not re-rendered, so nothing degrades. Text in the combined file is still selectable and searchable, and images keep their full resolution. One thing does not carry over: the bookmark panels of the original files, so add bookmarks afterwards if the recipient relies on them. The downloaded file goes to your Downloads folder unless your browser is set to ask where to save.

Workarounds to avoid

Microsoft Print to PDF is the most common suggestion and it does not merge anything. It prints one document at a time into a new PDF. Printing each file separately still leaves you with separate files, and re-printing can drop clickable links, bookmarks and fillable form fields along the way.

Opening PDFs in Word and copying them together is the second suggestion. Word converts each PDF into an editable document, which shifts layouts, swaps fonts and breaks tables, and then you export a new PDF from the damaged result. It is a lot of work to produce a document that no longer looks like the originals.

Free upload sites are the third. Many work, but they send every page of your documents to a server you know nothing about, often add a watermark, and sometimes cap the number of files. For a pack of personal or business documents, a tool that never uploads them is the safer default.

Handle protected, scanned and very large files

A password-protected PDF cannot be merged until it is unlocked, because its pages cannot be copied while encrypted. If the file is yours, or you are entitled to modify it, remove the password with Unlock PDF and merge the unlocked copy. Keep the protected original for your records.

Scans make merged files large. If the combined PDF is too big to email, compress the scanned inputs before merging rather than compressing the whole result — the guide to making a PDF smaller on Windows explains why that keeps your text-based pages sharp.

For a very large set — dozens of long documents — merge in batches. Combine the first ten, then the next ten, then merge the batch results. The output is identical, and you avoid running out of browser memory on an older PC.

Check the combined PDF

Open the merged file in Edge and compare its page count with the total of the parts. Scroll to the first page of each original document to confirm the order, and check the last page to make sure nothing was cut short.

Rename the result to describe the whole pack — your name, what it is and the date — because a file called merged.pdf is easy to lose and unhelpful to the person receiving it. Check the size against any upload or email limit before attaching it.

Keep the separate files until the combined PDF has done its job. If one document needs replacing, re-merging from the parts takes a minute. If you need to rearrange individual pages afterwards, Organize PDF lets you reorder, rotate and remove pages in the same way.

Frequently asked questions

Can Windows merge PDFs without extra software?

Not on its own. Windows can view and print PDFs but has no merge feature. A browser-based tool works in Edge or Chrome without installing anything.

Can I merge PDFs with Microsoft Print to PDF?

No. It prints one document at a time into a new PDF, so it cannot join several files, and re-printing can drop links, bookmarks and form fields.

Is there a limit to how many PDFs I can combine?

Not a fixed one. Because PDFNest merges files on your computer, the practical limit is your available memory. Very large sets can be merged in batches.
