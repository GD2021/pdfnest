How to Merge PDFs on a Mac

PBy the PDFNest Team·November 2, 2026·5 min read

A Mac can merge PDFs without any extra software, and it offers two built-in ways to do it. Both work well, and both have a quirk that catches people out: one changes your original file without asking, and the other decides the page order for you. This guide covers the built-in routes, a browser route that avoids both problems, and how to check the result before you send it.

Pick the right method for the job

The three routes suit different situations. A Finder Quick Action is fastest when you just want a handful of files stuck together. Preview is best when you want to combine files and then rearrange or remove individual pages. A browser tool is easiest when the order matters and you would rather not touch the originals at all.

Whichever you choose, merging is lossless. The pages are copied into the new document as they are, so text stays selectable and images keep their original resolution. You do not need to worry about the merged file looking worse than its parts.

Merge with a Finder Quick Action

Select the PDFs in a Finder window, right-click (or Control-click) one of them and choose Quick Actions, then Create PDF. macOS writes a new combined PDF into the same folder, named after the first file. Your original files are left untouched, which makes this the safest of the built-in options.

The catch is order. The files are combined in the order Finder lists them, which in most views is alphabetical by name. If your contract is called terms.pdf and your cover page is called cover.pdf, the cover lands first by luck rather than design. Renaming files with a leading number — 1-cover.pdf, 2-terms.pdf — puts you back in control.

The same Quick Action also accepts images, so you can include a scanned receipt or a photo alongside PDFs. Each image becomes its own page. If the image pages come out an awkward size next to your documents, the guide to combining PDFs and images covers making page sizes consistent.

Merge in Preview, without overwriting anything

Open the first PDF in Preview and turn on the thumbnail sidebar from the View menu. Drag the other PDFs from Finder into the sidebar, dropping each one where you want its pages to appear. You can then drag individual thumbnails to reorder pages, or select one and press Delete to remove it.

Here is the quirk: Preview saves changes to the open document automatically. Dragging three files into report.pdf means report.pdf now contains all of them, and the single-document version is gone unless you have a copy. Before you start, choose Duplicate from the File menu and work on the duplicate, or use Export as PDF at the end to write the result to a new file.

Preview is the right tool when you need page-level control after merging — dropping a blank page, moving an appendix, removing a duplicate. For that kind of fine adjustment on any computer, Organize PDF does the same job in a browser, and the reordering guide walks through it.

Merge in your browser with full control of the order

Open Merge PDF in Safari or Chrome and drag the PDFs from Finder onto the page. Drag files up and down in the list until the order is right, then merge and download the combined file. The originals are never modified, and you can see the order before anything is created.

The merge runs on your Mac, inside the browser tab. Nothing is uploaded to a server, which matters for the kinds of documents people usually combine — signed contracts, bank statements, application packs and medical letters. There is no account, no watermark and no limit on the number of files beyond your Mac’s memory.

This is also the method to recommend to someone else, because the steps are identical on a Mac, a Windows PC and a phone. If you are writing instructions for a colleague who may not use a Mac, the Windows guide and the phone guide cover the same process on those devices.

Fix the common problems

If one of the PDFs is password-protected, merging fails or produces a file that will not open properly, because the protected pages cannot be copied until they are unlocked. For a document you are entitled to modify, remove the password first with Unlock PDF, then merge the unlocked copy.

If the merged file is too large to email or upload, it is almost always because one of the inputs is a scan. Compress that file first rather than the combined result — the guide to making a PDF smaller on a Mac covers both Preview and browser options. Compressing before merging keeps the text-based pages untouched.

If pages appear sideways in the merged file, they were sideways in the original — merging does not rotate anything. Fix the orientation in Preview’s sidebar with the rotate button, or with Rotate PDF, and save the result before sending.

Check the merged PDF before you share it

Open the combined file and check the page count against the total of the parts. A shortfall usually means a file was missed; an excess usually means one was added twice. Scroll through the first and last page of each original document to confirm they landed in the right place.

Look at the file name and size too. A Quick Action names the result after the first file, which is rarely what you want the recipient to see. Rename it to describe the whole pack, and confirm the size is within any upload or email limit before you attach it.

Keep the separate originals until the combined file has been accepted. If someone asks you to replace one document in the pack, rebuilding from the parts takes a minute; extracting and replacing pages in a merged file takes longer and is easier to get wrong.

Frequently asked questions

Does merging PDFs in Preview change my original files?

It can. Preview saves edits to the open document automatically, so dragging other PDFs into it changes that file. Duplicate the first PDF before you start, or export the result as a new file.

Why are the pages in the wrong order after using Create PDF?

The Quick Action combines files in the order Finder lists them, which is usually by name. Rename the files with numbers first, or use a tool that lets you drag the order before merging.

Does merging reduce the quality of the pages?

No. Merging copies the existing pages into one document without re-rendering them, so text stays selectable and images keep their resolution.
